# Feature Design Prompt

Use this worksheet to clarify a proposed feature before implementation.

## Problem or opportunity

What user need or product goal does this address?

## Expected outcome

What should a user be able to observe or do?

## Decisions and constraints

Which product and technical decisions are already approved?

## State and interactions

What state changes, commands, and visible feedback are required?

## Open questions

List only decisions that materially affect the design or implementation.
